# One-by-One Summary Semantic Audit

Date: 2026-05-04

Purpose: strict sequential audit of every maintained summary in `../20_summaries/`.

Pass criteria:
- Summary is written as a synthesized summary, not raw source extraction.
- Research question, contribution, methodology, datasets/materials, findings, limitations, and project implications match the mapped source.
- No unsupported concept, method, dataset, synthesis, or project links.
- No boilerplate phrases such as "Semantic verification against", "Source-grounded framing", "The repair does not add limitations", or "Verification note".
- If source evidence is incomplete, the note explicitly says what is only partially verified.

Status key:
- `PASS`: checked against source and acceptable.
- `REWRITE`: rewritten during this audit.
- `NEEDS_SOURCE`: source unavailable or insufficient for full verification.
