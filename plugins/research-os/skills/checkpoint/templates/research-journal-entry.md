# Research Journal Entry Format

Append to `00_admin/process/journal.md` whenever an agent completes work. Append only, newest-first — never overwrite existing entries. Only add an entry if agent work happened this session. Scores and phase state are read from `passport.yaml` `pipeline.stages`; the journal explains the reasoning behind them (see `${CLAUDE_PLUGIN_ROOT}/rules/logging.md`).

### YYYY-MM-DD HH:MM — [Agent Name]
**Phase:** [Discovery/Strategy/Analysis/Writing/Review/Revision/Submission]
**Target:** [file or topic]
**Score:** [XX/100 or PASS/FAIL or N/A]
**Verdict:** [one line — key finding or decision]
**Report:** [path to full report]
