- **Project:** `create-project`, `research-os-help`
- **Knowledge:** `wiki-setup`, `add-vault`, `wiki-pull`, `wiki-push`, `wiki-ingest`, `wiki-maintain`
- **Routines:** `daily-summary`, `weekly-planning`
- **Learning (engram-adapted):** `learn`, `recall`, `coach`
- **Maintenance:** `check-update-upstream-repos`
