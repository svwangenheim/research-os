# Log

This is the chronological, unified record of activity across all thematic wikis and the personal
brain rooted here.

Use consistent headings so the file stays machine-readable and easy to scan.

Format:
## [YYYY-MM-DD] operation | title

Possible operation types: ingest, query, synthesis, maintenance, push, checkpoint.

For a multi-wiki root, prefix paths with the wiki name, e.g.
`cognitive-load/20_summaries/foo.md` or `innovation-policy/30_concepts/bar.md`, so an entry is
unambiguous about which wiki it touched.
