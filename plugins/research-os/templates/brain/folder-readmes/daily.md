# Daily

One note per calendar day, written by `/daily-summary` — not hand-authored (edit only to fix a wrong summary).

Each note (`note_type: daily`, template `daily_template.md`) holds:
- a per-project summary of what changed that day (from the day's commits)
- any relevant Slack / Microsoft 365 comms surfaced that day

`/weekly-planning` reads these back to review the week. The 22:00 scheduled agent writes today's note automatically.
