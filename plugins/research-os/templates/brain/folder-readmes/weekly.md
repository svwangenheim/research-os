# Weekly

One note per week (dated to that week's Monday), written by `/weekly-planning`.

Each note (`note_type: weekly`, template `weekly_template.md`) holds:
- last week's check-off (free-text status per goal, not a binary checkbox)
- this week's goals and open work timeslots
- calendar blocks created (or proposed)
- **Questions for next week** — open threads for future-me: contradictions noticed, entities that keep co-occurring but aren't linked, next actions left unnamed

The Friday 16:30 scheduled agent drafts this; you confirm goals and calendar.
