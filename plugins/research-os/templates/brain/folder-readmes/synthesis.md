# Synthesis

Personal and **cross-theme** synthesis — insight that spans wikis, tied to your own thinking. Distinct from a wiki's `90_synthesis/`, which is theme-internal.

Written by `/wiki-push` (`note_type: synthesis`, shared `synthesis_template.md`). This is durable thinking, not temporary chat output. Tag claims inline with a `(confidence: …)` level.

`wiki-maintenance-history/` is a **frozen migration archive** — provenance only, not active synthesis.
