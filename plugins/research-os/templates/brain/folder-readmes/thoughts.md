# Thoughts

Fleeting / thinking notes — the personal-layer capture inbox. **Low bar to write, high bar to keep.**

Each note (`note_type: thought`, template `thought_template.md`) captures a single idea plus a "Where it could go" line. Durable ones **graduate**:
- a reusable concept/method/dataset → down into a wiki via `/wiki-ingest`
- cross-theme or personal insight → `_brain/synthesis/`
- a durable lesson → `_brain/learning/`
- a project idea → a project note

Everything else is deleted. Nothing should live here permanently.
