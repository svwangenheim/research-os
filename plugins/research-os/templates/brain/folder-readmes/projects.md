# Projects

One note per active or potential project — the bridge between the long-term wikis and concrete active work. Written and kept current by `/checkpoint`.

Each note (`note_type: project`, template `project_template.md`) has two parts:

- **Orientation** (kept current, overwritten each checkpoint) — a "read this first" snapshot: what the project is in one breath, the research question, the gap, the data and empirical strategy in plain terms, where we stand right now `(as of <date>)`, and where the technical detail lives.
- **Journal** (append-only, newest first) — dated `### YYYY-MM-DD` entries with **Done** / **Next**, the session-by-session play-by-play.

Frontmatter (`status`, `summary`, `supersedes`, …) makes each project visible in the catalog (`index.md`). Objective knowledge learned here goes *down* into a wiki via `/wiki-ingest`; cross-theme insight goes *up* into `_brain/synthesis/`.
